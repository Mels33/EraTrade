# Торговая и риск-спецификация EraTrade (MVP)

Версия спецификации: **1** · Утверждена: 2026-11-17 · Изменена: 2026-11-17 (без testnet, лимит номинала 20 USDC)

Машиночитаемые значения находятся в [`config/strategy.toml`](../config/strategy.toml).
При расхождении этого документа и конфигурации источником истины считается конфигурация,
а расхождение — ошибкой, которую нужно исправить.

## 1. Рынок

| Параметр | Значение |
|---|---|
| Биржа | Hyperliquid, только perpetual futures |
| Инструмент | BTC (asset ID берётся из актуального `meta`, не хардкодится) |
| Таймфрейм | 1h |
| Решения | только по закрытым свечам, один раз на свечу |
| Горизонт прогноза | 4 свечи (4 часа) |
| Маржа | isolated, плечо 2x |

## 2. Правила решений

| Сигнал | Позиции нет | Есть long | Есть short |
|---|---|---|---|
| `BUY` | открыть long | ничего (не увеличиваем) | закрыть short (без разворота) |
| `SELL` | открыть short | закрыть long (без разворота) | ничего (не увеличиваем) |
| `HOLD` | ничего | держать | держать |
| `EXIT` | ничего | закрыть | закрыть |

Дополнительно:

- **Выход по времени:** позиция закрывается через 8 свечей, если раньше не сработали stop-loss или `EXIT`.
- **Приоритет:** stop-loss и выход по времени важнее сигнала модели.
- **Повторный вход:** не раньше следующей закрытой свечи после выхода.
- **Разворот:** запрещён. Противоположный сигнал может только закрыть позицию.
- **Усреднение, мартингейл, пирамидинг:** запрещены.
- **Любая ошибка данных, признаков или модели** даёт `HOLD`.

## 3. Ордера

| Действие | Тип |
|---|---|
| Вход | IOC limit с ценой не хуже `mid ± max_slippage` |
| Выход | IOC limit, `reduceOnly` |
| Защита | биржевой trigger stop-market, `reduceOnly`; лимит на 5% хуже цены срабатывания |

На этапах 6–8 каждый ордер подтверждается оператором вручную (`require_manual_confirmation`).

## 4. Размер позиции

```text
risk_amount = min(10 USDC, equity × 0.5%)
stop_distance = max(1.5 × ATR(14), entry_price × 0.5%)
size = risk_amount / stop_distance
```

Затем размер урезается (никогда не увеличивается) до:

- номинала не выше 20 USDC (на время технических тестов; целевое значение 200 USDC);
- плеча не выше 2x;
- доступной маржи;
- `szDecimals` (округление вниз).

Если после этого номинал меньше биржевого минимума (10 USDC) — сделка запрещается.

## 5. Лимиты

| Лимит | Значение | Действие при превышении |
|---|---|---|
| Риск на сделку | min(10 USDC, 0.5% equity) | размер урезается |
| Макс. номинал позиции | 20 USDC (тесты), затем 200 USDC | размер урезается |
| Макс. плечо | 2x | размер урезается |
| Дневной убыток | 2% equity | запрет новых входов до ручного разбора |
| Недельный убыток | 5% equity | запрет новых входов до ручного разбора |
| Сделок в день | 4 | запрет новых входов до следующего дня |
| Мин. расстояние до stop | 0.5% цены | stop отодвигается до минимума |
| Макс. спред | 5 bps | вход отклоняется |
| Макс. проскальзывание | 10 bps | граница цены IOC-ордера |
| Задержка решения | ≤ 90 с после закрытия свечи | сигнал пропускается (`HOLD`) |
| Тишина WebSocket | > 30 с | запрет входов, переподключение и сверка |
| Ордер в `UNKNOWN` | > 30 с | сверка с биржей; повторной отправки нет |

В дневной убыток входят реализованный PnL, комиссии, funding и нереализованный PnL открытой позиции.
Equity для расчёта риска и лимитов = spot USDC + perp account value (на аккаунте единый баланс).
Превышение лимита убытка — устойчивый запрет входов (снимает только оператор); лимит сделок в день сбрасывается сам.
Дневной период считается по UTC.

## 6. Режимы работы

| Режим | Сеть | Ордера |
|---|---|---|
| `DISABLED` | любая | нет |
| `TESTNET` | testnet | да, только testnet (не используется: решение 2026-11-17) |
| `SHADOW` | mainnet | нет, сигналы сохраняются |
| `LIVE_PAUSED` | mainnet | только закрытие и защита, новые входы запрещены |
| `LIVE_ENABLED` | mainnet | да |

- `LIVE_ENABLED` нельзя задать в конфигурации: только ручная команда оператора с подтверждением и записью в аудит.
- После перезапуска бот стартует не выше `LIVE_PAUSED`.
- Нарушение любого лимита оставляет бота в текущем режиме, но запрещает новые входы.

каким объёмом и при каких условиях оно будет отклонено.
