# Регламент эксплуатации маркет-мейкера

Аккаунт: основной (единый счёт, залог — USDC на споте). Монеты и лимиты — `config/strategy.toml`
`[mm]`: заявка 12 USDC, позиция ≤ 25 USDC на монету, дневной убыток ≤ 2 USDC.

## Аварийные действия

| Ситуация | Действие |
|---|---|
| Что-то непонятно | панель → «Пауза» (или `eratrade pause -r "..."`): заявки снимаются, позиция остаётся |
| Закрыть всё | панель → «Остановить и закрыть позиции» (`STOP`): режим DISABLED, маркет-мейкер закрывает позиции |
| Маркет-мейкер не отвечает | `scripts/eratrade.sh mm-stop`; проверить заявки и позицию в интерфейсе Hyperliquid, снять вручную |
| Компьютер уснёт/выключится | заявки останутся на бирже (scheduleCancel недоступен до оборота $1 млн) — перед этим «Пауза» |
| Сработал дневной лимит | входы запрещены автоматически; разобрать сделки во вкладке «Торговля», запуск — не раньше следующего дня |
| PostgreSQL потерян | `mm-stop`; восстановить дамп (`pg_restore`), `alembic upgrade head`, `mm-start` |

## Ежедневно

- панель: «Торгует», маркет-мейкер работает, итог дня и расход лимита убытка;
- запросы адреса не падают быстрее, чем растёт оборот;
- бэкап за сутки есть (`ls backups/`), раз в неделю — `scripts/restore_check.sh`.
